# 验收记录

此目录仅提交人工验收报告和[证据索引](evidence-index.md)。报告中的结论属于记录对应的历史版本，不代表当前环境或后续版本已经通过验收。

原始 JSON、模型回复、进程输出、重复尝试和本机诊断保存于本机 `data/acceptance/`，保持迁移前的目录结构。该目录由 Git 忽略；克隆仓库不会获得这些原始文件。2026-10-28 归档的逐文件路径、大小和 SHA-256 清单位于本机 `data/acceptance/archive-manifest.json`。索引保留各次报告原有状态及主要结果文件的 SHA-256，不能用摘要替代原始运行证据。

验收和诊断脚本默认输出到 `data/acceptance/`。复验后，按需将验证范围、代码版本、CLI 版本、结果和限制整理成 Markdown 报告，再提交到此目录；不要直接提交整份运行输出。`accept-agents.ts` 仍支持通过 `PIPELINE_ACCEPTANCE_DIR` 显式指定输出目录。

原始证据已从当前工作目录移出，但此前提交仍保留在 Git 历史中，本次没有改写历史。清理本机 `data/` 时，请按需要备份或转存验收归档。
